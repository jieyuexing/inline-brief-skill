How local image inlining & selection copy work (expand)
Cards 01 and 02 reference local PNG files (assets/opt-lowpoly.png and assets/opt-pixel.png). During compile.mjs, local raster images inside the source directory are validated (relative path only, no .., <= 2 MiB) and inlined as data:image/...;base64,... so the compiled page makes zero network requests. Cards 03 and 04 use <ib-preview> with theme-native SVG tokens that automatically follow Dark and Light themes.
