Client L1 cache L2 Redis Postgres The handler asks L1 first. A hit returns in well under a millisecond and the walk ends here. The key is absent or expired locally, so the same key is fetched from Redis over the network. Only now does the request reach Postgres. A single-flight lock keeps concurrent misses on the same key down to one query. The row is written to Redis and L1 with a jittered TTL, so the next reader stays on the fast path.
